Mjukvarulösningsarkitekt i Örebro

Vanliga frågor

Svar på det företag oftast frågar om möten, kostnad, tjänster och hur ett projekt går till.

Är ni ett stort konsultbolag?

Nej. Du pratar direkt med mig, samma person som designar och bygger lösningen.

Måste vi byta ut våra nuvarande system?

Sällan. Ofta räcker det att koppla ihop det ni redan har eller bygga det som saknas runt omkring.

Pratar du svenska?

Jag lär mig svenska och pratar flytande engelska. Skriftligt material kan vara på svenska.

Arbetar du bara i Örebro?

Nej. Jag bor i Örebro och arbetar med kunder i hela Sverige. Vi börjar alltid med ett kort videosamtal eller telefonsamtal.

Vad kostar ett första möte?

Ingenting. Vi tar 15 minuter på video eller telefon, och du får ett kort förslag efteråt.

Skräddarsydda system

Hur vet jag om vi behöver ett eget system?

Om ni lägger mycket tid på manuell inmatning, Excel och mejl trots att ni har standardprogram, kan ett eget system eller ett tillägg löna sig. Det reder vi ut på ett första möte.

Kan vi börja i liten skala?

Ja. Vi börjar med den del som sparar mest tid och bygger vidare när den fungerar i vardagen.

Bokningssystem

Räcker inte en färdig bokningstjänst?

Ofta gör den det. Ett eget bokningsflöde är värt det först när ni har särskilda regler, flera resurser eller behöver koppla bokningar till andra system.

Kan kunderna få påminnelser?

Ja, påminnelser via mejl eller sms kan skickas automatiskt före besöket.

Integrationer

Måste vi byta system för att integrera?

Sällan. De flesta system har API eller export, och då kan datan flyttas automatiskt mellan dem.

Vad händer om ett system inte har något API?

Då kan import och export via CSV eller Excel ofta automatiseras i stället.

Dashboards och rapportering

Var hämtas siffrorna ifrån?

Direkt från de system ni redan använder, till exempel webbutik, bokning eller ekonomi, så att ingen behöver klistra in data för hand.

Kan rapporterna exporteras?

Ja, till Excel och PDF, till exempel för styrelse eller revisor.

Affärssystem och ekonomi

Ersätter det vårt bokföringsprogram?

Inte nödvändigtvis. Ofta är det bättre att bygga inköp och lager runt det ekonomisystem ni redan har och koppla ihop dem.

Varför spelar redovisningskunskap roll?

Ett affärssystem måste ge korrekta underlag till bokföringen. Masood har ACCA-kvalifikation som redovisningstekniker.

E-handel och webbutiker

Kan webbutiken visa samma lagersaldo som butiken?

Ja, med en synk mellan lager och webbutik visar båda samma saldon.

Vilka betalsätt går att använda?

Kort, PayPal och andra betallösningar beroende på vad webbutiken stöder.

Ska vi ta 15 minuter?

Berätta vad som tar onödig tid. Vi tar ett kort videosamtal eller telefonsamtal först – utan kostnad.
