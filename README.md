# orebro-profile

Static multi-page site for Masood Ahmad (systemutvecklare,
Örebro), served at https://renvolve.biz via GitHub Pages
(branch `master`, root `/`). No JS apps, no external loads.

## Structure
| Path | Content |
|------|---------|
| `/` (sv), `/en/` | Home pages, Swedish default |
| `tjanster/`, `en/services/` | Service hub + 6 service pages |
| `insikter/`, `en/insights/` | Articles |
| `om-mig/`, `kontakt/` | About, contact (sv; en mirrors) |
| `systemutvecklare-orebro/` | Local landing page (sv + en) |
| `kallor-och-licenser/` | Credits and licenses (sv + en) |
| `assets/` | Self-hosted fonts, icons, images, OG |
| `css/main.css` | Compiled from `scss/` |
| `LICENSES/` | Third-party license texts |
| `sitemap.xml`, `robots.txt`, `404.html` | SEO / errors |
| `CNAME` | Custom domain (keep) |

## Editing
HTML is generated by a Python build script (`gen.py`, kept
outside this repo); regenerate and copy the output here rather
than hand-editing pages. Styles: edit `scss/`, then
```
npx --yes sass@1.83.0 --no-source-map --style=compressed \
  scss/main.scss css/main.css
```

## Preview
```
python3 -m http.server 8791 --bind 127.0.0.1
```

## Deploy
Push to `master`; GitHub Pages publishes automatically.
