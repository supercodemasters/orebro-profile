Integrationer – system som pratar med varandra

Samma order skrivs in i webbutiken, i ekonomisystemet och i ett kalkylark. En integration flyttar datan automatiskt och minskar fel.

Vanliga integrationer

  • Webbutik och lager som visar samma saldon
  • Order och fakturor till ekonomisystemet
  • Kunddata mellan CRM, nyhetsbrev och support
  • Import och export via API, CSV eller Excel

Erfarenhet

  • Integration av IBM Cognos BI med SugarCRM, inklusive ETL och inloggning (SSO)
  • Synkning mellan QuickBooks och SugarCRM
  • Synk av lager och priser mot en Magento-webbutik
  • Betalningar via kort, PayPal och Amazon Payments; sms-verifiering och mejlutskick
  • Integration mot externa enkät-API:er (CINT, Pollfish) för 50 000+ användare
  • Mobilbetalning via MTN Mobile Money (Ghana)

Så går det till

Vi ses 15 minuter i Örebro eller på distans. Du får ett kort förslag, och vi börjar i liten skala. Jag finns kvar för support efteråt.

Vanliga frågor

Måste vi byta system för att integrera?

Sällan. De flesta system har API eller export, och då kan datan flyttas automatiskt mellan dem.

Vad händer om ett system inte har något API?

Då kan import och export via CSV eller Excel ofta automatiseras i stället.
